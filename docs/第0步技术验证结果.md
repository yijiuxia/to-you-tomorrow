# 第 0 步技术验证结果（2026-11-07）

测试电脑：i9-13900H、RTX 4050 6 GB 显存、16 GB 内存。Godot 4.6.1，NobodyWho 13.0.0。
模型：Qwen 2.5 3B（q4_k_m，1.8 GB），没有微调，人设和判断规则都是临时写的。
测试：`tests/model_test/lines.csv` 的 30 句话，每句前清空对话历史。

| 项目 | 有显卡 | 只用 CPU（测 15 句） |
| --- | --- | --- |
| 每句回复（中位数） | 0.94 秒 | 3.0 秒 |
| 最慢一句 | 1.5 秒 | 3.4 秒 |
| 第一句（含预热） | 2.2 秒 | 5.4 秒 |
| 加载模型 | 5～8 秒 | 2.5 秒 |
| 合法 JSON | 30/30 | 15/15 |
| intent 选对 | 22/30 | 12/15 |

只用 CPU 的数字来自这台电脑的高性能 CPU，不代表普通电脑。

## 判断准确度

- `intent`：错的 8 句主要在"撤回来""向你求助""只是聊天"，常被判成 `continue`。
- `player_attitude`：只对 10/30，大多数都判成了 `encourage`，4 句限制的话有 3 句判成鼓励。这个标签会改数值，上线前必须改善。
- 这些"正确答案"是写测试时人工定的，有的句子可以有不同理解。

## 显存

测试时显存峰值 5.4 GB（共 6.1 GB），其中约 2.7 GB 是其他程序已占用的，模型约占 2.7 GB。
还没有和 3D 画面同时跑过，第 2 步有场景后要复测。

## 打包大小

Windows 版：游戏程序和插件 237 MB + 模型 1.8 GB，合计约 2.1 GB。目前项目还没有正式画面，美术和声音另算。

## 还没验证

- 真正没有独立显卡的电脑（需要另一台电脑）。
- 模型和 3D 画面同时运行。
- 打包后的游戏实际运行（要等第 1 步有主场景）。

## 踩过的坑

1. 格式表要把文件原文传给插件。Godot 解析 JSON 会把 3 变成 3.0，插件会报错。
2. 只限制格式还不够：模型可能在字段之间无限输出空格，一句话卡 16 秒，最后 JSON 也不完整。`model_output_schema.json` 里关掉了多余空格（`x-guidance`），并限制了文字长度，改完后 30 句全部合法。
3. 插件程序文件 143 MB，超过 GitHub 单文件上限，没进仓库，安装方法见 `addons/README.md`。

## 怎么重新跑

在项目文件夹里运行（把模型路径换成实际路径）：

```
Godot_v4.6.1-stable_win64_console.exe --path . res://scenes/tests/model_test.tscn -- --model=模型路径
```

这是手动聊天。加 `--auto --out=结果文件.json` 是自动跑分，再加 `--cpu` 只用 CPU。
