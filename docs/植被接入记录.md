# 连续污染植被接入（2026-11-21）

位置：真实游戏 E:/GODOT/to-you-tomorrow 的 EarthView，不是独立样板工程。

- A 区：污染裸地使用水泥色地表，仅废墟边裂隙带有矮草。
- B/C 区：污染地表连续暗紫苔层，上层细草为主、低矮阔叶和枯草穿插。世界坐标噪声控制高低和密度；不按等距行列排布；跨格最小间距采样。墙边和道路边按距离渐变。
- 净化为零、种植、挖坑、建筑占用及河道/道路区域排除毒草；净化、种植和挖坑同时切换地表。状态变化才重建草层。
- 采用九类几何节点预生成资产，各4变体；按空间块合并绘制。基础草远处隐藏，连续苔毯保留。

测试：unit_tests、earth_tests、ui_tests、chat_tests、playthrough_test、earth_vegetation_tests 均退出0。UI/流程测试首次因沙箱的 user:// 不可写失败，改用独立测试用户目录后通过。没有改用户存档。

真实 ARK-01 原镜头（1280×720，RTX4050 Laptop，Forward+，每区120帧）：A 平均25.81ms；B 21.63ms；C 19.58ms。包含真实地球模型和机器人，不含完整UI与语言模型负载，不是完整游戏帧率保证。

现有限制：苔毯仍是带微表面细节的地表着色，近看体积感不足；废墟邻近关系以游戏占地为依据，某些外伸模型的贴墙位置仍需人工修整。草海边缘、特色植物组合和色调仍待视觉确认，不把测试通过当成美术定稿。

建议在正常镜头下复查：墙角/碎石处穿插、交互物遮挡、快速移动时草层距离切换；执行净化、建造、种植后确认旧毒草退去。
