# 插件安装说明

## NobodyWho 13.0.0（本地运行模型）

插件的程序文件有 143 MB，超过 GitHub 单文件 100 MB 的上限，所以没放进仓库。换电脑或重新下载仓库后，要手动装一次：

1. 下载 https://github.com/nobodywho-ooo/nobodywho/releases/tag/nobodywho-godot-v13.0.0 里的 zip。
2. 把 zip 里 `bin/addons/nobodywho/` 下的 `libnobodywho-godot-x86_64-pc-windows-msvc-release.dll` 放到本文件夹的 `nobodywho/` 里。

只放 Windows 版即可。其他系统的文件用不上，全部解压有 1.2 GB。
